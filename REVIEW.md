# Проверка CampusDigest

Автор адаптации и доработок — Рябуха Олег.

Изучены README, дерево проекта, requirements, модели и исторические миграции,
API/схемы, Telegram-меню и обработчики, оба паука и pipeline, Docker/CI, LICENSE.
Основа сохранена: FastAPI, SQLAlchemy 2 с asyncpg/PostgreSQL, Alembic,
Scrapy, python-telegram-bot 20, aioschedule. Исходных тестов в репозитории не было.
Файл MIT LICENSE сохранён без изменений.

Предметная область — публичные университетские новости и студенческие объявления.
Вместо общеполитических новостных сайтов работают ИТМО и основной портал НИУ ВШЭ.
Категории API и Telegram согласованы: Наука, Образование, Студентам, Кампус, ВСЕ.
Сохранены JWT/регистрация, фильтрация, лимит, отметки прочитанного, парсинг и очистка
вручную и по расписанию, HTML-представление и опциональный Instant View.
Внутреннее имя Article и API-маршруты сохранены. Дата API теперь ISO 8601,
без прежнего ошибочного ручного сдвига на три часа.

Устранены жёсткие системные пути и вызов Python вне текущего venv, ошибки отмены
фоновых задач и aioschedule на Python 3.11. API запускается без Telegram-токена;
бот и расписание включаются отдельными параметрами. Для read marks добавлена
миграция `c41d6a2b0e19_unique_read_marks.py`: отдельный PK и UNIQUE(article_id,user_id)
вместо составного PK с autoincrement. Это сохраняет запрет повторных отметок.
Тематическое изменение полей таблиц не потребовалось.

Удалены старый SSH-деплой, отправка Docker-образов в чужой DockerHub, неиспользуемые
middleware и старая версия handlers. Compose собирает приложение из местных файлов,
сохраняет PostgreSQL и постоянные данные бота. `.env.example` содержит заглушки.
CI запускает только тесты и проверку зависимостей. Лицензионный файл сохранён
без изменений; история Git не менялась.

## Ограничения

Docker daemon недоступен. Реальное применение исторических и новой миграций в
PostgreSQL и сборка/запуск контейнеров не проверены; SQLite-интеграция не заменяет
эту проверку. PostgreSQL остаётся основной БД. Нет токена Telegram, публичного
HTTPS webhook и собственного RHASH: отправка в Telegram, webhook и Instant View
внешним сервисом не проверены. Исходные библиотеки выводят два предупреждения
(cgi/Twisted и per_message/ConversationHandler); тесты проходят.

Запуск: скопировать `.env.example` в `.env`, заполнить SECRET и параметры БД,
запустить PostgreSQL, выполнить `.\.venv\Scripts\python.exe -m alembic upgrade head`,
затем `.\.venv\Scripts\python.exe run.py`. Подробнее в README.
